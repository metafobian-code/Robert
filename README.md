# Robert’); DROP TABLE Students

*Metáfora 404*

Poema animado sobre la metáfora, el signo y el símbolo (Wittgenstein, *Tractatus* 3.326), la psicología interconductual y la inyección SQL. Tiene trece planos con versos que se teclean con cursor, ventanas de código y JSON, y antiprismas en 3D dibujados en canvas.

## Ver

Abre `index.html` en cualquier navegador. Es un solo archivo, sin dependencias aparte de Google Fonts.

Para publicarlo con GitHub Pages: **Settings → Pages → Deploy from a branch → `main` / root**.

## Controles

- **Espacio** o clic: pausa / reproducir
- **← →**: plano anterior / siguiente
- **Inicio**: volver al principio
- Barra de progreso: saltar a cualquier plano

Respeta `prefers-reduced-motion`: si está activo, muestra el texto completo sin animación.
